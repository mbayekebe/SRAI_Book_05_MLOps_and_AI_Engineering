# PU-B05-C01 — MLOps Foundations

Controlled instructional release candidate for SRAI Book 5, Lesson 1.

## Learning outcome

Learners move from an experimental model to a traceable, tested and governed release candidate. The production unit joins lifecycle reasoning, reproducible execution, data and model evidence, operational tests, monitoring, rollback and accountable approval.

## Included components

| Component | Purpose |
|---|---|
| `lesson/` | 42-page controlled lesson in Word format |
| `notebook/` | Portable VS Code/Google Colab laboratory and evidence bundle |
| `assessment/` | Exercises, solutions and 100-mark marking guide |
| `executive/` | Decision-maker brief |
| `slides/` | 29-slide presentation with speaker notes |
| `video/` | Narration and production plan |
| `github/` | Repository-facing documentation |
| `linkedin/` | Publication copy for professional audiences |
| `website/` | Web page content and structured metadata |

## Quick start

1. Open `notebook/V5_N01_mlops_foundations.ipynb` in Google Colab or VS Code.
2. Run all cells from a clean Python runtime.
3. Confirm all contract tests pass and inspect the generated `artifacts/pu_b05_c01/` directory.
4. Compare the evidence with the release gates in the lesson.
5. Do not treat technical success as publication authorization.

## Control position

The data are synthetic, the model is instructional, and the canonical candidate is intentionally **BLOCKED pending governance approval**. It must not be used for farm, education, health, housing, credit, insurance, benefit or other consequential decisions.
