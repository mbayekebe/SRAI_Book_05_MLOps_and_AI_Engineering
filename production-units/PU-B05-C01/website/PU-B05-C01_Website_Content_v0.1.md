# MLOps Foundations

## From experimental model to governed operating system

MLOps Foundations teaches learners to connect machine-learning development with reproducibility, testing, deployment controls, monitoring and accountable institutional decisions.

### What learners build

Using a portable synthetic agricultural-risk laboratory, learners generate a deterministic dataset, compare baseline and candidate models, evaluate regional slices, hash artifacts, execute contract tests, measure drift, assemble a model card and produce a fail-closed release manifest.

### What makes this lesson different

The workflow does not convert a successful notebook run into automatic authorization. Technical evidence and governance approval are separate controls. Learners must identify the owner, evidence, threshold and decision associated with every lifecycle gate.

### Sector applications

- **Agriculture:** seasonal change, regional performance and operational risk.
- **Education:** learner protection, intervention evidence and appeal routes.
- **Health:** clinical governance, human escalation and safety monitoring.
- **Habitat:** geographic equity, service access and accountable housing decisions.

### Production-unit components

Controlled lesson · Portable notebook · Exercises and marking guide · Executive brief · Presentation with speaker notes · Video-production materials · Release and validation assets

> Educational use only. The data and model are synthetic. The release candidate remains blocked pending governance approval.
