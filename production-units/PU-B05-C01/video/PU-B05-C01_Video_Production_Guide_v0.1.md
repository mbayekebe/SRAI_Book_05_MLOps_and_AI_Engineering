# Video Production Guide — PU-B05-C01

| Segment | Visual direction | On-screen evidence | Production note |
|---|---|---|---|
| Opening | Model metric dissolves into a lifecycle map | “A model ≠ an operating system” | 5-second title sting; restrained motion |
| Lifecycle | Animated circular path with control gates | Owners, evidence, gate, decision | Reveal one stage at a time |
| Lineage | Notebook and manifest split-screen | Seed, hashes, configuration | Zoom only on legible fields |
| Evaluation | Metric strip plus regional chart | Aggregate and slice metrics | Use chart animation, not card stacking |
| Governance | Gate barrier across promotion arrow | Technical PASS / Authorization BLOCKED | Gold for decisions; red only for block |
| Monitoring | Drift curve connected to response path | PSI, owner, trigger, rollback | Preserve causal sequence visually |
| Sectors | Four environments around shared control core | Agriculture, Education, Health, Habitat | Use distinct icons/photography with one palette |
| Close | Evidence inventory resolves into seal | Evidence before promotion | Hold end card for 6 seconds |

## Accessibility and delivery

- Provide accurate captions and a reviewed transcript.
- Keep on-screen text at least 32 px in a 1080p composition.
- Do not communicate PASS/BLOCKED through color alone.
- Describe charts and control states in narration.
- Export a 1920×1080 master, H.264 review copy and audio-only WAV.
- Confirm every visual claim against the controlled lesson or notebook evidence.
